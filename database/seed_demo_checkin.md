# 归寝演示数据说明

## 启用方式

在 `backend/src/main/resources/application.yml` 中取消注释并启用：

```yaml
app:
  seed-demo:
    enabled: true
```

然后**重启后端**。生成完成后建议改回 `false`，避免重复清空演示日期的打卡数据。

## 前置条件

1. 已执行 `database/test_data.sql`（学生、楼栋、房间）
2. 已执行 `database/migration_teachers.sql`（managers 表）
3. （可选）已执行 `database/migration_checkin_manager.sql`；未执行时种子程序会自动补齐 `check_exceptions.handle_result` 列
